# Chronicord

Бесплатная программа для Windows, которая сохраняет историю каналов Discord **через твоего бота** — в архив, который можно открыть в браузере, выложить на сайт или просто хранить.

Без регистрации, без рекламы, без телеметрии. Открытый код, лицензия MIT.

# Зачем Chronicord, если есть DiscordChatExporter?

Для использования DiscordChatExporter разработчик установил странные правила игры: либо ты соглашаешься, что Россия агрессор — либо ты и есть этот самый агрессор.
Им все равно какие мотивы преследуют людей, которые используют эту программу. Им все равно что может повлечь их трактовка политической ситуации в мире, они просто играют с вами, чтобы удовлетворить собственное эго.
Моя цель показать, что вы не виноваты в том, что родились в какой-то стране. Вы не должны ни перед кем извиняться, что-то подтверждать, стоять на коленях только потому, что ваше правительство делает выбор за вас.
Приятного использования программой, если что-то не работает или требует доработок — сообщайте!

## Возможности

- Окно с выбором серверов, каналов, категорий
- Текстовые каналы, каналы объявлений, текстовые чаты голосовых, **ветки** (активные и архивные) и **форумы**
- **Вложения**, аватарки, кастомные **эмодзи** (в тексте и реакциях), **стикеры**, **опросы** с результатами, встраивания, ответы, пересланные сообщения
- Выгрузка **всего набора эмодзи и стикеров сервера** с описанием (`manifest.json`)
- Фильтр по периоду, лимит сообщений, «только сообщения выбранных пользователей»
- **Замена или скрытие ников** перед выгрузкой: заменить ник, скрыть, или исключить сообщения пользователя полностью. Действует на автора, упоминания `@ник` и ответы; ID тоже заменяется
- Форматы: **JSON** (для своего сайта), **HTML** (готовый просмотрщик с поиском, фильтрами, тёмной/светлой темой), **TXT**, **CSV**
- Интерфейс и HTML-архив на **русском и английском**
- **Докачка**: можно остановить в любой момент, следующий запуск продолжит с того же места и докачает только новое

## Быстрый старт

1. Скачай `Chronicord.exe` из [Releases](../../releases).
2. Создай бота: [discord.com/developers/applications](https://discord.com/developers/applications) → **New Application** → вкладка **Bot** → **Reset Token**.
3. Там же включи **Message Content Intent** (иначе текст сообщений будет пустым). Для выбора пользователей из списка — ещё **Server Members Intent**.
4. **OAuth2 → URL Generator**: scope `bot`, права `View Channels` и `Read Message History` (для закрытых архивных веток — `Manage Threads`). Открой ссылку и добавь бота на сервер.
5. Запусти Chronicord, вставь токен, нажми «Подключиться», отметь каналы → «Начать выгрузку».

Архив откроется кнопкой «Открыть архив в браузере» (`index.html` в папке выгрузки).

> Windows может показать «Система Windows защитила ваш компьютер», потому что exe не подписан платным сертификатом. Нажми «Подробнее → Выполнить в любом случае». Если сомневаешься — проверь контрольную сумму или собери программу сам (ниже).

## Если что-то не так

- **0 сообщений в канале или ветке, без ошибки.** У бота нет права **«Читать историю сообщений»** в этом месте. Discord в таком случае не выдаёт ошибку, а просто возвращает пустой список. Ветки берут права из **родительского канала/форума**: проверь права канала и его категории.
- **У сообщений пустой текст.** Включи боту **Message Content Intent**.
- **Не работает «Выбрать из участников».** Включи **Server Members Intent** или добавляй пользователей по ID.

## Безопасность и приватность

- Программа работает **только с токеном бота**. Токены пользовательских аккаунтов не поддерживаются: их использование нарушает правила Discord.
- Сеть: только `discord.com` (API) и `cdn.discordapp.com` / `media.discordapp.net` (файлы). Больше никуда ничего не отправляется — можно проверить в [`chronicord/core/api.py`](chronicord/core/api.py).
- Токен не пишется в логи и файлы. Если отмечено «Запомнить», он хранится в **Диспетчере учётных данных Windows**.
- Готовые exe собираются **GitHub Actions** прямо из этого кода ([workflow](.github/workflows/build.yml)), к каждому релизу прикладывается `SHA256SUMS.txt`. Проверить: `certutil -hashfile Chronicord.exe SHA256`.
- Выгружай чаты своих серверов. Перед публикацией архива с сообщениями других людей спроси их согласия — для этого и есть замена/скрытие ников.

## Сборка из исходников

Нужен Python 3.10+.

```bat
git clone https://github.com/Manik1348/chronicord
cd chronicord
build.bat
```

Готовый файл: `dist\Chronicord.exe`. Запуск без сборки: `pip install -r requirements.txt` и `python main.py`.

## Структура архива

```
Chronicord/
  index.html                 список всех каналов
  assets/                    аватарки, эмодзи, стикеры (общие для всех каналов)
  server-assets/<сервер>/    полный набор эмодзи и стикеров сервера + manifest.json
  <канал>_<id>/
    index.html, data/        HTML-просмотрщик
    part-0001.jsonl          сообщения (по одному JSON на строку, части по 20 МБ)
    meta.json, state.json    сведения о выгрузке и точка продолжения
    media/                   вложения
    messages.txt / .csv
```

Формат строки JSONL — в [FORMAT.md](FORMAT.md) (на русском).
